# MiSalud+ — TP Integrador Programación III

Aplicación web de gestión médica para pacientes y profesionales de la salud.

## Objetivo

Facilitar el acceso a la información médica, el registro de consultas, la administración de tratamientos y el seguimiento de medicación.

## Tecnologías

- NestJS y TypeScript
- React y Vite
- MongoDB y Mongoose
- REST y GraphQL
- JWT
- Docker y Docker Compose

## Arquitectura

- API Gateway
- Microservicio de usuarios
- Microservicio clínico
